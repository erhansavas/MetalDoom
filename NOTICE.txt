MetalDoom

MetalDoom is an independent macOS port of the DOOM engine source code. It is
not affiliated with, endorsed by or sponsored by id Software or ZeniMax
Media. DOOM is a trademark of id Software; the name is used here only to say
which game this port runs.

Game data

  No game data is included: no WAD files, maps, textures, sprites, sounds,
  music or demos from DOOM. You need your own copy of DOOM or The Ultimate
  DOOM (DOOM.WAD) or the DOOM shareware release (DOOM1.WAD).

  The sounds of the gore effects are synthesized by the program at run time;
  their only recorded material is the game's own DSSLOP sound, read from the
  player's WAD file.
